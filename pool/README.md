The pool is admitted source: one directory per CMP code at a version, containing exactly the source that index entry describes and nothing more.  Being here means it has been read, indexed, given an as-built spec, bound to tests, built reproducibly, and signed in by the committee.  Upstream code is not in the pool until it has been through that door, and only the smallest reviewable unit a failure asked for comes through.  Nothing in this directory is ever pre-compiled.
