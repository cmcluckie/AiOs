AiOS, part 3.  "I added a second program.  The operating system changed by zero lines."...

Every CS student did Towers of Hanoi once.  Move four disks between three pegs, one at a time, never a big one on a small one.  Fifteen moves, and the elegant way to find them is recursion.

It's the second program on AiOS, and I picked it because it needs nothing new from the machine.  It writes, it stops.  Same two doors hello world used.

So here's what I was actually testing: can you add a program without touching the operating system?  On most systems that question doesn't even parse, because the operating system is a thing you install programs into.  Here, the operating system is 170 lines that take over the machine, run one program through two doors, and halt.  I built hello world against it.  Then I built Hanoi against it.  Same loader, byte for byte, same hash.  Diff to the operating system: zero lines.

That's the whole bet.  Each program on the ladder asks for exactly one new thing: memory next, then input, then a clock, then a disk, then two programs at once.  Each one adds a door.  None of them moves an old one.  Hello world keeps booting under every version that follows, and that's a test we run every time.

Next rung: linked lists.  The pointer chapter.  The program will ask for memory, and for the first time the loader has to find out what this machine actually has.
