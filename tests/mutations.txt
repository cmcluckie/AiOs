# Mutations: jig/mutate breaks the code on purpose, one line at a time, and runs
# the named test against the broken copy.  "red" means the test must go red; if
# it stays green, the test is decoration (tenet 8).  "survives" records a
# mutation we know no test catches yet, and why: each one is a finding.
#
# Fields are separated by space-bar-space; a sed expression may contain || but not " | ".
# A mutation that stops the build proves nothing: jig/mutate reports it as NO-BUILD.
#
