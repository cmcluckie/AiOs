> /* Wait for one byte, then take whatever else has already arrived.  The system
>  * call runs with interrupts off (the int 0x80 gate cleared them, as Linux's
>  * int 0x80 entry does), so the wait loop opens the tick again (sti): a tick
>  * (IRQ 0) then preempts this kernel wait and hands the processor to the other
>  * program, and the saved frame is resumed inside the loop when its turn comes
>  * (the scheduler's switch, in the gate).  Taking the bytes stays under the
>  * saved flags, so one program's bytes never interleave with another's.  The
>  * TECH-DEBT 2 this was is gone. */
