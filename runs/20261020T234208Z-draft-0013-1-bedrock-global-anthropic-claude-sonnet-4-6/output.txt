Now I have a complete picture of cat.c. Let me analyze what it needs:

1. **Writes to stdout (console)** → `CAP.tty.write@1`
2. **Reads from stdin** → `CAP.tty.read@1`
3. **Opens and reads files by name** → `CAP.fs.read@1`
4. **Allocates memory (malloc)** → `CAP.mem.alloc@1`
5. **Exits** → `CAP.proc.exit@1`

The program needs a filesystem with read capability, stdin read, stdout write, memory allocation, and exit. It uses `fstat` on stdout to determine block size for the raw path — that's part of the file/console abstraction. It does not write files, does not need VGA, serial device directly, disk device directly, or time.
