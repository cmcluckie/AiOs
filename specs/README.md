Specs are as-intended clauses: what a component should do, written by humans from the purpose, never derived from code.  One TOML file per SPEC code at a version, one sentence each, precise enough that a test can turn it red.  A clause nobody can write a failing test for is not a spec, it is a wish.  As-built specs live in the index beside the component they describe; the diff between the two is the bug list.
