# Findings 0046: the race that did not start

Source: part 24, 2026-11-25, out/race24.sh on the jig at 706e5b8 (Linux 6.18.55,
Ryzen 9 5900X, 4 cpus), the file out/drag/drag.bin (sha256 c92b33e76f49a742...),
as the drag flavor builds it.  Car 2 booted it alone under KVM on
MACHINE.serial-timer@1.  The new test below ran in Claude's workspace, under
software emulation, not on the jig.
Goes to: the architects (Chris and Claude).

1. **Car 1, the same file on the jig's Linux, six heats in two runs:** 25,032,
   23,252, 22,987, 23,711, 24,438 and 24,429 passes in 5 s.

2. **Car 2 stopped in every heat:** "Guru Meditation #0000000E.00000004
   program 1 stopped": a page fault, the program reading address 4.

3. **Why.**  Each pass the sieve takes its 64 KiB buffer, then its 4 KiB
   record, and gives them back in that order (drag.c lines 73, 77, 217 and
   218).  Memory is handed out downward, so the buffer is given back while the
   newer record below it is still in use.  The fix to the munmap hole taken
   in decision 0123 (plan-drag try 4) moves the low edge only when the block
   given back is at it: the buffer becomes a hole that is never handed out
   again, and 64 KiB is lost every pass.  The machine runs out, calloc answers
   NULL, and the sieve reads its record at NULL plus 4.  The first munmap
   (decision 0122) got this order right by moving the edge too far, and was
   wrong the other way (findings 0044 item 5).  No try ever had AVX and a
   munmap of either kind together, so no try ran the sieve on it.

4. **The test that sees it.**  TST.gate.munmap-order@1 (SPEC.gate.14@1): 64 KiB
   then 4 KiB, given back in the order taken, 20,000 times.  Red at 706e5b8 in
   the workspace: "mmap2 failed at round 235".  Green with a throwaway munmap
   that marks each page given back and moves the edge up past every page given
   back, as are TST.gate.munmap@1 and TST.gate.munmap-keep@1; not kept: it is
   the 3090's to find.

5. **The 28,100 and 28,763 of findings 0045 stand as practice laps**: try 6's
   AVX on the first munmap, which this order does not trip.
