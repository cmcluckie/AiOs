# Findings 0009: the licence was never decided

Source: a public comment on part 1, 2026-10-12.
Goes to: humans who own the constitution.

1. **The comment.**  A developer pointed out on LinkedIn that AiOs lifts
   GPLv2 code from Linux, compiles it into the same image as code marked MIT,
   and that the result is a derived work that must be GPL.  On the combined
   image he was right: the loader links the lifted serial driver and timer
   code into one binary, so every image we build is a work based on Linux and
   can only be distributed under GPL-2.0-only.  LICENSE said "MIT except
   lifted/", which covered each file and said nothing about the whole.  (It was
   not a clean-room claim and nothing was hidden: every lifted file kept its
   GPL header and its origin record, the source was public, and no binary was
   ever distributed.)

2. **Nobody chose MIT.**  Claude put an MIT licence on the repository in the
   commit where petition 0000 first booted, as a default.  Part 4's ours and
   theirs split wrote "pool/ is ours, MIT" into the rules and findings 0004,
   describing what was there rather than deciding it.  A licence is Chris's
   decision and should have been one, with a reason, from the start.

3. **Decision (Chris, 2026-10-12): the whole repository is GPL-2.0-only.**
   MIT bought nothing: every image that boots is GPLv2 anyway, and the only use
   MIT allowed beyond that was taking our loader without Linux's lines, which
   is not what the project is for.  "Version 2 only" because Linux is
   GPL-2.0-only, not "or later"; GPLv3 cannot be combined with it.  Chris is
   the only author, so the relicence needs nobody else's consent.

4. **What changed.**  LICENSE (the GPL-2.0 text, with a preface saying why);
   the SPDX header of every file in pool/, 13 of them, plus one added to each
   machine script; `licence` in 11 index entries; the schema's example; the
   rule in CLAUDE.md; the README; jig/donecheck, which now fails a pool
   component without a GPL-2.0-only header.

5. **Committed versions were touched, comments only.**  Committed component
   versions never change; this is the one exception, and it is a comment line.
   Checked: every loader built before and after the change is byte-identical
   (loader@1 5b4601bf374c5f45, @2 2de65f6b6787f146, @3 de3ad40c1e7bb631, @4
   e7605306629dcbe1, in Claude's workspace).

6. **For the future.**  A part lifted from anywhere but Linux must have a
   licence that can be combined with GPL-2.0-only, checked before the lift; if
   not, it is a finding, not a lift.  Written into CLAUDE.md.
