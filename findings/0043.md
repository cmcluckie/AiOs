# Findings 0043: the fix builder was blind to its own test

Source: part 24, 2026-11-08, the 3090's first night on the clock call
(out/plan-drag.toml, job plan-drag-1, TST.gate.clock@1).  Read from
out/agent/plan-drag/jobs/plan-drag-1-try1/.
Goes to: the architects (Chris and Claude).

1. **Seven hand-ins, seven times the same answer.**  "Hand-in N judged: fail.
   the test it was given is still red; 0 newly red."  Nothing else.

2. **What the test said, and the builder never saw.**  suite.txt after the
   builder's change: "FAIL  TST.gate.clock@1  12s  only 1 readings".  The call is
   answered now; the clock it reads does not move.  That is half a fix, and the
   builder had no way to know which half.

3. **Why.**  A failed fix was told what tests that went green-to-red printed
   (newly_red), never what the test it was given printed.  The lifter has been
   shown that since decision 0111 (findings 0032 item 5 flagged the fix path and
   it was left).

4. **The change.**  A failed hand-in now carries the given test's FAIL line and
   what was printed just before it, the lifter's printed_before, under "What the
   test it was given printed:".  TST.agent.build@1 goes red without it (the toy
   test prints a line before its FAIL, and the forge hand-in must be shown it),
   and a thirteenth mutation proves it.
