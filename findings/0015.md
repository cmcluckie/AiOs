# Findings 0015: one source reader for the quartermaster and the historian

Source: a conversation, 2026-10-13, not a petition.  Chris's question,
Claude's proposal, Chris agreed.
Goes to: whoever builds the quartermaster (plan 7.0).

1. **The question.**  The quartermaster and the historian both read Linux
   source.  Does one use the other, or do both use something shared?
   Building the reading twice would be a waste, and two readers would
   drift apart.

2. **They ask different questions of the same source.**  The quartermaster
   asks what a piece of code is and what it needs: what it calls, which
   hardware it touches, what it depends on.  The historian asks whether it
   changed since it was lifted and whether that matters.  Neither should
   own the reading, so neither calls the other.

3. **Decided: one shared source reader.**  Given a Linux commit, a file and
   line ranges, it answers questions about them.  Both agents call it.  It
   is not an agent: it decides nothing and does not act on the nucleus.

4. **It splits like the historian does.**  A mechanical half answers what
   calls what, what touches which port, which lines moved; same answer every
   time, no model, so the referee may rely on it.  The default with the
   history is cscope (Bell Labs, early 1980s), which Linux supports with
   `make cscope`; anything else needs a reason here.  An AI half answers
   what the code is for and whether a change matters, and is given the
   mechanical answers so it is not guessing.

5. **The mechanic's code goes through it too.**  A fix the mechanic
   proposes is new code, so it goes to the quartermaster like code lifted
   from Linux, and the same reader reads it.  One front door for code,
   whoever wrote it.  The mechanic and the quartermaster never share a
   model or prompt.  Chris, 2026-10-13.

6. **Not in the posts yet.**  It does not exist, and part 13 already asks
   readers to learn enough words.  It gets a name, through the human-only
   rule for words, when it is built.

7. **Where it lives until then.**  Plan 7.0, ahead of the rest of the
   quartermaster, and the historian and quartermaster entries in CLAUDE.md.
