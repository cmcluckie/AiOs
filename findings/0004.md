# Findings 0004: ours and theirs

Source: the question "if those 57 lines change upstream, how do we pull them
back in?", 2026-10-11.  Goes to: humans who own the constitution.  Decided the
same day; applied in this commit.

1. **Lifted and written code were mixed.**  The loader carried a GPL header
   because fifteen of its lines were attributed to Linux, and the serial part
   sat in pool/ next to hello.  Two licences and two provenances in one tree
   with no boundary is how a repository becomes unauditable.
   Resolution: pool/ is ours, MIT; lifted/ is theirs, own licence; a component
   with one lifted line lives in lifted/.  The loader was re-examined: the
   struct layouts are a public ABI (Xen's header, MIT) and the descriptor
   values are the Intel SDM's, so it is ours and MIT.  The serial part moved
   to lifted/.

2. **Provenance was a comment.**  Line numbers in a C comment cannot be
   checked by a script.  Resolution: origin.toml per lifted part, defined in
   schema/entries.md: repository, commit, commit date, file, blob id, line
   ranges, who and when, what was cut.  `jig/upstream verify` proves every
   range's blob id against the upstream clone.

3. **"Pulling back in" was undefined.**  Distributions merge the whole tree
   and inherit every conflict.  We carry ranges, so git can answer the only
   question that matters: did upstream touch these lines since we took them?
   `git log -L start,end:file commit..HEAD` does exactly that, per range, and
   `jig/upstream watch` runs it for every origin record.  Tested red by
   pretending the lift was from April 2025: it named the one upstream commit
   that touched the range.  Resolution: upstream is watched, never merged.  A
   change that matters is lifted again as the next version of the part;
   petitions on the old version keep building what they built.

4. **The historian now has a first job.**  Design.md gives the historian
   "pull upstream fixes through the door".  Its placeholder is jig/upstream;
   it reports and never changes anything.  Needs an upstream clone with
   history on the jig, which is a tool-table row (git, already present) and
   disk, not a new tool.

## Open

- The lift date in origin.toml for serial.8250 is approximate to the half
  hour; from now on it is recorded at the moment of lifting.
- `watch` says lines moved; it does not say whether the change matters.
  That judgment is a human's until the committee exists.
