# Findings 0006: the machine listens

Source: petition 0003, a reverse-Polish calculator, 2026-10-11.  First input.
Goes to: humans who own the constitution.

1. **The reference caught a real bug.**  The calculator's number parser checked
   for overflow after multiplying, in an `unsigned long`.  On this machine
   that is 32 bits, so 99999999999 wrapped to 1215752191 before the check saw
   it.  The program was written; an independent Python reference was written
   from the same spec; the transcript test compared them and went red at byte
   320 for exactly the right reason.  First time a test on the ladder caught
   something a human missed.  Fixed by checking before multiplying.  Tenet 8
   doing its job.

2. **No echo, and Enter is \r.**  QEMU puts a real terminal in raw mode for
   `-serial stdio` (chardev/char-stdio.c): no local echo, ICRNL off, so Enter
   arrives as \r; output translation stays on.  A pipe sends \n.  So the
   program echoes what it reads, handles backspace, and treats \r, \n and \r\n
   each as one Enter.  None of that is the loader's business; the door hands
   over bytes and nothing else.  Recorded because it is the kind of thing a
   terminal driver normally hides, and here nothing hides anything.

3. **Arithmetic can end the machine.**  Divide by zero and INT_MIN / -1 raise
   the processor's divide fault.  This machine has no interrupt table, so a
   fault is a triple fault, which is a reset, which with -no-reboot is the
   machine exiting.  The calculator refuses both before dividing.  The loader
   does not catch faults because nothing has petitioned for fault handling;
   when something does, that is the rung where the landlord learns to evict.

4. **Polling, not interrupts.**  The read door spins on the line status
   register.  With one program that is waiting for input anyway, a spin costs
   nothing anyone asked for.  Interrupts arrive when a petition needs the
   machine to do something else while it waits, which is rung 9.6.

5. **The serial part moved up a version, through the door.**  CMP.serial.8250@2
   is @1 plus the receive lines (8250_early.c 110-126, serial_reg.h 147),
   lifted at the same upstream commit, with its own origin record.  `upstream
   verify` checks both versions: 34 ranges, all green.  @1 is untouched, so
   hello, Hanoi and Life still build exactly what they built, and also boot
   under loader@3 unchanged.
