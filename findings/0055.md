1. **The third briefing was poor.**  Sonnet 4.6, 46,906 tokens in, 2,371 out,
   $0.1763, friend@2.  The builder had started from the kept change (findings
   0054), with which the test says "the Linux program never printed elf hello".
   The briefing explained the page fault at address 0, the failure at the
   commit, which the kept change had already ended; it argued with itself in
   the text it sent ("Wait", "Re-read the fault"); and the change it drew zeroes
   the program's memory and then copies the program's pieces out of that same
   memory.

2. **Why.**  Three things, none the model's alone.  It was shown both failures,
   the commit's first.  All it wrote was sent, its working out with its answer.
   And it could check nothing: one message, no way to look.

3. **What the machine was doing, which no one could see.**  The test said only
   what was missing.  QEMU's own record of every interrupt (-d int), two seconds
   under emulation: 196 ticks and every call (1001, the clock, 89,573 times;
   4, write, twice) came from 001xxxxx, the stopwatch.  Nothing ran anywhere
   else; the Linux file asks to start at 08049000.  So the Linux program was
   never given a turn: not refused a write, never started.  PART.share@2 stops
   loading programs at the first one the gate gives no space for, and says
   nothing.  At the commit the same record shows the fault: "fault 0e at
   00400047 touching 00040000".

4. **A red rung now says so.**  tests/programs/dragshare-rungs.sh, on a red run,
   boots the archive once more for two seconds under emulation and prints one
   more line: where the ticks landed, which calls came from where, the first
   faults, and where the Linux file asks to start.  The builder and the friend
   are shown it (the test's line is now kept to 900 characters, not 200).  No
   change to the kernel: the machine is asked, not the program.

5. **The friend, rebuilt** (SPEC.agent.13@1, TST.agent.friend@1, ten mutations,
   each red; run in Claude's workspace on saved replies):

     included, ten looks at most.
   - It must quote: every place a briefing points at is a file and lines copied

     and nothing is sent.

     lines), the shape of the change, what to do first, what it could not check.
     What it says on the way is not.

     builder's disk.

     calls a builder at most.
   - The score: each run keeps friend_calls, friend_dollars and friend_outcome:
     pass, moved (the test fails another way), same, or worse (it no longer
     builds).  Each call is kept as friend-N.md and friend-N-asked.txt and
     recorded in runs/.
