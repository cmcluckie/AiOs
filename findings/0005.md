# Findings 0005: memory, the first resource

Source: petition 0002, Conway's Game of Life, 2026-10-11.  The loader's first
change since 0000 booted.  Goes to: humans who own the constitution.

1. **A flat binary cannot say how much memory it needs.**  The program format
   (program.ld) dropped zero-initialised data, as every flat-binary linker
   does, so a program's variables lived past the end of its file.  Hello and
   Hanoi survived by luck: nothing else used that memory.  The moment the
   loader started handing out memory from the end of the file, Life's first
   block landed on Life's own grid pointer and the program hung before its
   first byte of output.  Resolution: CMP.loader@2's program format writes
   the zeros into the file, so the file's end is the program's end.  Costs
   bytes; honest.  CMP.loader@1 keeps the latent bug because it is committed;
   0000 and 0001 keep working under it and also under @2 (tested).  A format
   with a header, or a tiny ELF, is the eventual fix and is a petition when
   something needs it.

2. **The memory map is the firmware's, not the machine's.**  The hypervisor
   reports one RAM range, 0 to 64 MiB; the firmware (qboot) rewrites it into
   the 1980s PC layout: 0 to 639 KiB RAM, a 1 KiB reserved hole for a BIOS
   data area nothing uses, 128 KiB marked "ACPI" on a machine with ACPI off,
   64 KiB of firmware, then RAM from 1 MiB.  The loader uses only the region
   it was loaded into, which is the honest choice: the rest is a legacy nobody
   petitioned for.  Ledger entry; not fixable from our side of the handoff.

3. **Refusal is the test.**  "Give me 128 MiB on a 64 MiB machine" returning 0
   is the only line in this rung that can go red on its own.  Tenet 8.

4. **Alignment and zero.**  Blocks are 16-byte aligned (the ABI's stack
   alignment) and a request of 0 bytes is refused rather than given a pointer
   to nothing.  Both are decisions no textbook states; recorded.

5. **The diff was not zero.**  35 lines of C and one door entry.  Hello and
   Hanoi boot under @2 unchanged, which is the ladder's rule holding for the
   first time it was actually tested.
