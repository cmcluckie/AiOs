# AGT.referee@1, as built

What it does: reads the constitution and the catalogue and says yes or no, naming a rule and a catalogue number.  No model, no judgment.  C11, one file, pool/AGT.referee@1/referee.c, 966 lines, built on the jig with the host compiler (libc for files; popen for the compiler, git's short hash and nm).  pool/AGT.referee@1/referee is a twelve-line shell wrapper that builds it when the source is newer than the binary and hands over.  First written in shell on 2026-10-15 and rewritten in C the same night: the referee is permanent code, and C is the language of everything permanent in AiOs.  The shell version was the spec by example; the C one passes the same four probes and writes the same referee-results file line for line.

Commands: `check FLAVOR` (rules 1, 9, 19), `hardware CODE SRC` (rule 12, the list in constitution/instructions.toml, on the program's own assembly from the same compiler, CC and CFLAGS from the builder), `rules` (rules 2 to 8 on every petition, written to tests/referee-results.txt), `lines FILE` (rule 13, verbs from constitution/verbs.toml, nouns from the catalogue), `petition FILE` (a draft petition is well-formed: every line a comment, a table header or a field and never prose, the petition fields, a purpose that exists, a role and an admitted flag on every component, SPEC codes as reasons (rule 2), a future expiry (rule 9), and every catalogue number with a version that resolves or comes with a component not yet admitted (rule 1); it prints the components still to be admitted, one per line; added for part 19, it checks the shape and does not say a draft is buildable).  Added for part 21 (decision 0065): `artifact FLAVOR` (rule 11 on the kernel as linked: every part in out/FLAVOR/kernel-parts.txt, or the kernel's depends before @8, listed by a petition; every capability the kernel and its parts expose asked for, switched off unless asked and its symbol absent from `nm` of the image, or listed for the flavor in constitution/extras.toml; an asked-for capability whose symbol is missing, or a listed extra the kernel no longer has, refused too), `probe FLAVOR SRC` and `probes` (rule 22: every test program written against the system call table says where it boots and makes only calls those flavors ask for, or expects refused; a script that boots it on one flavor's kernel boots it where it says, the system call names read from the kernel's own door.h).  The decision ledger is jig/ledger, a script, because it reads git history.

Reads: constitution/, index/, specs/, tests/*.toml, tests/programs/, petitions/, flavors/, the door.h of each kernel, and out/FLAVOR/ (the linked kernel and its parts list).  Writes: tests/referee-results.txt only.  Touches no hardware, opens no socket, runs no model.

Called by: jig/aios build (check before, artifact on the linked kernel, hardware after), the probes in tests/programs/.  jig/ledger is called by jig/test (every commit since the last run) and .githooks/pre-commit.

Not yet: running the tester itself (plan 3.7), rules 10, 14 to 16 and 20 as checks, rule 11's VM half, a signed verdict file, a schedule for expiry, rules 17 and 18 (still said by the builder).  Hand-written, as the definition of done allows until plan 7.1.
