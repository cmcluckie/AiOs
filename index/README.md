The index is the menu: everything that can be named in a petition.  `cap/` holds one TOML file per CAP code: the permission's name, what it lets a component touch, and the kernel or hardware mechanism that enforces it.  `cmp/` holds one TOML file per CMP code at a version: where the source lives in `pool/`, its dependencies (CMP), what it exposes (CAP), what it requires (CAP), the as-built spec derived from that source, and the signed admission record.  Admission requires: source only, a licence the constitution accepts, an as-built spec, at least one TST that can fail, a build that reproduces bit-identical on two hosts, and a committee review against the invariants.  An entry without a signed admission is a draft the referee will not build from.
